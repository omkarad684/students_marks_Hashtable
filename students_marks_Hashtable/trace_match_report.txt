## 3. Hash Function

The Mid-Square Method is used.

Steps:
1. Square the given key.
2. Extract the middle digit or digits from the square.
3. Take the extracted number modulo the table size.

The implementation uses:

h(k) = middle digits of k² mod 11

The number of extracted digits is based on the number of digits in m - 1. For m = 11, two middle digits are extracted.

Note: This report follows the digit-extraction convention implemented in the submitted C++ program.
